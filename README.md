# 🐍 贪吃蛇小游戏

一个用纯 HTML + CSS + JavaScript 制作的经典贪吃蛇游戏，可直接部署到 Vercel。

## 功能特点

- 经典贪吃蛇玩法
- 实时得分与最高分记录（本地存储）
- 支持键盘方向键 / WASD 控制
- 手机端触摸方向按钮
- 随着得分增加，速度会逐渐加快
- 美观的暗色霓虹风格界面

## 如何游玩

1. 点击「开始游戏」或按空格键
2. 使用方向键（↑ ↓ ← →）或 WASD 控制蛇的移动
3. 吃到红色食物得分，撞墙或撞到自己则游戏结束

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 部署到 Vercel

1. 将本项目推送到 GitHub
2. 在 Vercel 导入该仓库
3. 点击 Deploy 即可
